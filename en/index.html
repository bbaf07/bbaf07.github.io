How I work.

Every project follows the same four steps. The last one, testing by trying to break the rules, is the one most people skip.

01
  1. 01

    Understand the need

    I start from the client's real problem and its limits: mobile payment, phone use, legal duties.

  2. 02

    Set the data and access rules

    I design the database schema and write the access rights inside the database.

  3. 03

    Build the API and the interface

    I build the backend and the front end, with server-side validation everywhere.

  4. 04

    Test what matters

    I write tests that try to break the rules: self-approval, adding a payment, reading restricted content.
