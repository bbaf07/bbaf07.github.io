C'est pour toi ?

Portail d'objets perdus et trouvés.

L'application rapproche automatiquement les déclarations par similarité de texte (sentence-transformers) et d'image (CLIP), stockées dans PostgreSQL avec pgvector. Ma méthode.

Chaque projet suit les mêmes quatre étapes. La dernière, tester en essayant de contourner les règles, est celle qu’on saute le plus souvent.

01
  1. 01

    Comprendre le besoin

    Je pars du problème réel du client et de ses contraintes : paiement mobile, usage sur téléphone, obligations légales.

  2. 02

    Poser les données et les règles d'accès

    Je dessine le schéma de base de données et j'écris les droits d'accès dans la base de données.

  3. 03

    Construire l'API et l'interface

    Je développe le backend et le front, avec une validation systématique côté serveur.

  4. 04

    Tester ce qui compte

    J'écris des tests qui tentent de contourner les règles : auto-validation, ajout de paiement, lecture de contenu réservé.
